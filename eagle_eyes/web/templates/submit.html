An upload is a weaker input than a scanned failure, and the report will say so. There is no sibling directory to check the screenshot against, so it is recorded as uploaded rather than as a verified pairing. There is no modification time on pasted source, so the reuse gate cannot tell whether the code changed — and therefore refuses to reuse an earlier answer rather than risk serving a fix for code that no longer exists.

Without it the diagnosis rests on the log alone: it can name what failed, but it cannot point at the line.
